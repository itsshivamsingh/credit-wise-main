   • Go to: https://www.mongodb.com/cloud/atlas
   • Create free M0 cluster
   • Get connection string
   • Add your IP to whitelist
   • Save your MONGO_URI

2️⃣  CONFIGURE PROJECT (2 minutes)
   • Edit: server/.env
   • Add your MONGO_URI
   • Keep other values as-is

3️⃣  RUN APPLICATION (1 minute)
   • Terminal 1: cd server && npm install && npm start
   • Terminal 2: cd client && python -m http.server 8000
   • Open: http://localhost:8000

API ENDPOINTS (11 Total)
═══════════════════════════════════════════════════════════════════════════════

AUTHENTICATION
   POST   /api/auth/register       Register new user
   POST   /api/auth/login          Login user
   POST   /api/auth/logout         Logout user
   GET    /api/auth/me             Get current user

LOANS (Protected with JWT)
   POST   /api/loans/apply         Submit loan application
   GET    /api/loans/history       Get user's loans
   GET    /api/loans/:id           Get specific loan
   PATCH  /api/loans/:id           Update loan status
   GET    /api/stats/dashboard     Get dashboard stats

HEALTH CHECK
   GET    /api/health              Server status

   ✅ Run npm install in server folder
